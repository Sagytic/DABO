## 2024-05-23 - Authentication Form Accessibility
**Learning:** The application historically relied on native `alert()` for user feedback, which is disruptive. Authentication forms now utilize native browser validation (`required` attribute) and semantic `<form>` structure instead.
**Action:** When working on forms, replace manual JS checks and `alert()` calls with HTML5 validation attributes and semantic `<form>` structure to improve accessibility and UX.
